# CyberSec Practice Lab

Website latihan cybersecurity yang berjalan sebagai static site lokal.

## Menjalankan
Buka `index.html` langsung di browser, atau gunakan server lokal:
`python3 -m http.server 8000`
lalu buka `http://127.0.0.1:8000/`

## Isi
- Reflected XSS: demo output aman dengan `textContent`
- SQL Injection: perbandingan konsep query tidak aman vs parameterized query
- Authentication: checklist secure authentication
- Security Headers: konsep CSP, HSTS, dan header lain
- Log Analysis: latihan membaca pola log
- Network Basics: konsep IP, port, DNS, HTTP/S

Lab sengaja dibuat lokal dan tidak menyerang target eksternal.
