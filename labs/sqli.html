LAB 02

SQL Injection

Simulasi aman: perhatikan bagaimana aplikasi seharusnya memperlakukan input sebagai data, bukan bagian dari query.

UNSAFE CONCEPT:
"SELECT * FROM users WHERE name = '" + input + "'"

SAFE CONCEPT:
SELECT * FROM users WHERE name = ?
parameter = input

Checklist

Gunakan prepared statements, least privilege pada akun database, validasi input, error handling yang aman, dan logging.
